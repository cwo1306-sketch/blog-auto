# 카드뉴스 디자인 시스템 v2 (2026 트렌드 반영)

2026-10-21. 기존 "사진 풀블리드 + 하단 스모크그레이 그라데이션 + 흰/노랑 헤드라인"을 대체한다.

## 리서치 요약

검색 가능한 2026년 자료는 대부분 마케팅·디자인 툴 업체 블로그라 수치는 참고치로만 본다. 그래도 여러 출처가 같은 방향을 가리킨다.

| 흐름 | 근거 | 적용 |
|---|---|---|
| **타이포가 주인공** — 3~4단어가 화면을 채우는 대형 그로테스크, 좁은 행간, 왼쪽 정렬. 첫 장의 굵은 글씨와 높은 대비가 스와이프를 결정 | 캐러셀 타이포 트렌드(Supaslides), 캐러셀 가이드(Social Habit, Slidy) | 표지 헤드라인 84px ExtraBold, 왼쪽 정렬, 본문 제목 64px |
| **잡지(에디토리얼) 페이지처럼** — 단색·질감 배경 위 큰 헤드라인 | 템플릿 모음(UI Creative), 폰트 트렌드(Simplified) | 종이 톤 단색 배경 + 그레인 질감 |
| **쿨그레이 → 웜뉴트럴** — 베이지·체스트넛 등 따뜻한 중성색, 거기에 채도 높은 포인트 한 색 | 2026 디자인 예측(We and the Color, Adobe Express, G2, DesignRush) | 종이색 #F3EEE4 + 잉크 #141414 + 형광 #FFE500 한 색 |
| **질감·개성** — 그레인, 하프톤, 약간의 불완전함 | Picsart, G2 | 전 장 그레인 오버레이(불투명도 11%) |
| **번호 매긴 단계(01, 02)·컬러 블로킹** | 2026 캐러셀 트렌드 모음(My Social Boutique, Scrolo) | 본문 장 큰 번호, 장 유형별 배경색 교대(종이 → 잉크 → 형광) |
| **첫 3장은 각각 단독으로 읽혀야** — 알고리즘이 중간 장을 따로 노출 | 원포인트 블로그 | 모든 본문 장에 제목+완결 문장, 출처 줄 |
| **저장·공유 CTA가 마지막 장** | 폴라애드, Carouselli | 마무리 장을 형광 전면으로, CTA 알약 버튼 |
| **4:5, 안전 영역, 모바일 본문 24pt 이상** | 하이아웃풋클럽, Veeso, Social Habit | 1080×1350, 여백 64px, 본문 36px |
| 캐러셀 저장률 3~5%(교육형), 상위 5~15% — 업체 표본 | Carouselpost, Carouselli | 7단계 지표 판정 기준의 참고치 |

국내 뉴스 계정(뉴닉·어피티·스브스뉴스)의 2025~26 시각 분석 자료는 검색으로 확인되지 않았다. 카카오 템플릿·캐럿 프롬프트 갤러리에서도
"단색 배경 + 타이포 중심 + 형광펜 강조"가 반복적으로 보인다.

## 왜 스톡 사진 문제도 같이 풀리는가

사진이 풀블리드일 때는 사진의 질이 카드의 질이었다. v2에서는 사진이 **상단 액자 요소**(세로의 40% 안팎)로 줄고, 웜 틴트와 채도 -15%로
한 톤으로 묶이며, 헤드라인이 시선을 가져간다. 뻔한 스톡 사진의 영향이 줄고, 비전 검수의 '하단 여백' 기준도 덜 중요해진다
(대신 액자 안에서 '무관·로고·얼굴'만 거르면 된다).

## 시스템

- **색**: 종이 `#F3EEE4`, 종이2 `#E9E2D4`, 잉크 `#141414`, 잉크2 `#4A4842`, 뮤트 `#8A867C`, 형광 `#FFE500`.
  형광은 글자색으로 쓰지 않는다(종이 위 대비 1.1:1). **형광펜 블록**(`<mark>`)과 **전면 배경**으로만.
- **글꼴**: Pretendard. 표지 96/800(하단 기준 정렬, 사진은 세로 36%), 본문 제목 64/800, 본문 36/400(행간 1.55), 라벨 24/700, 숫자 카드 240~380/800.
- **장 유형과 배경 리듬**: 표지(종이) → 본문(종이, 번호 01·02·03) → 숫자(잉크 반전) → 마무리(형광 전면).
- **사진**: 액자 28px 라운드, 2px 잉크 테두리, 채도 .85, 웜 틴트 10%, 하단 종이색 페이드 28%.
- **고정 요소**: 좌상단 "AI로 재가공한 뉴스" 알약 라벨, 좌하단 출처, 우하단 n/6.
- **QA(render.py)**: 글자(잉크)와 배경 어두운 쪽 5퍼센타일 대비 ≥ 4.5, 텍스트가 사진 액자와 겹치지 않음, 그리드 3:4 크롭 안전, 제목 줄바꿈, 폰트 로딩, 8MB.

## 포인트 색 비교 (2026-10-21)

형광 노랑 `#FFE500`과 주황빨강 `#FF4D1F`를 같은 6장으로 렌더해 비교했다. 주황은 더 강하지만 마무리 장(전면 배경) 잉크 대비가
5.3:1로 노랑(13.7:1)보다 크게 낮고, 뉴스 계정의 '친절한 브리핑' 톤에는 노랑이 맞다고 판단해 **노랑 유지**. 바꾸려면 `--hl` 변수 하나.

## 비전 검수 가중치

v2에서 사진이 액자로 들어가 하단 여백의 중요도가 낮아졌고, 관련성 약한 사진이 더 눈에 띈다. 가중치를 관련성 0.5 / 하단 0.2 / 톤 0.3으로
조정(이전 0.4/0.35/0.25). 실측: 5장 "작지만 강한 티니"가 라이터 든 손(관련성 약함) → 작은 전구(3.5점)로 바뀜.

## 실측 (재렌더, 카카오 비전 인코더 6장)

대비 13.7~15.1:1(이전 5.6~8.0), QA 이슈 0. 파일 크기 0.07~0.3MB.

## v2.2 혼합 폰트 (2026-10-21, 채택)

Pretendard 단독 · 혼합 · 전체 주아체 세 버전을 같은 원고로 비교한 뒤 **혼합**을 채택했다.

| 장 | 글꼴 | 이유 |
|---|---|---|
| 표지 헤드라인 | 배달의민족 주아체 90px | 피드에서 멈추게 하는 장. 친근함·계정 개성이 득 |
| 마무리 요약 | 배달의민족 주아체 64px | 저장·공유를 부르는 장 |
| 본문 제목·본문·숫자·인용·비교·라벨 | Pretendard | 수치와 발언을 전하는 장은 신뢰감이 우선. 주아체 숫자는 둥글어 가볍게 보이고, 긴 본문은 읽는 속도가 떨어진다 |

- 주아체는 굵기가 하나(Regular)라 `font-weight: 400; font-synthesis: none` 으로 가짜 굵게를 막고, 자폭이 넓어 크기를 한 단계 낮췄다.
- 글꼴 지정 순서: 로컬 설치명(`BM JUA_OTF` 맥 / `BM JUA_TTF` 윈도우 / `배달의민족 주아`) → 구글 폰트 `Jua`(OFL, 같은 글꼴) → Pretendard.
  로컬 렌더링 PC에 배민 주아체나 Jua 중 하나가 설치돼 있어야 한다.
- 라이선스: 구글 폰트판 Jua 는 SIL OFL 1.1, 배민 폰트도 상업 이용 무료. 폰트 파일 자체의 판매·재배포만 금지.
- 위험 관리: 주아체는 광고·밈에 흔해 가벼워 보일 수 있다. 표지에만 쓰는 이유이고, 2주 니치 테스트에서 표지 폰트별 저장률을 비교해 최종 확정한다.
- 전체 주아체 테마는 `CARDNEWS_THEME=jua`(`templates/theme_jua.css`)로 남겨 둔다.


## v2.3 색 체계와 퍼스널 컬러 (2026-10-21, 채택)

### 문제 (v2.1 노랑)
- 노랑 하나를 형광펜·숫자·비교 라벨·마무리 배경·인용부호에 돌려써 역할 구분이 없었다.
- 출처 글씨 #948F86 의 종이 대비 **2.98:1** — 24px 작은 글씨 기준(WCAG AA 4.5:1) 미달.
- 인용부호·밑줄로 쓴 노랑의 종이 대비 **1.17:1** — 비텍스트 요소 기준(3:1) 미달, 사실상 보이지 않음.
- 마무리 노랑 #FFE566 이 카카오 #FEE500 과 색상각 **0.9°** 차이 — 이 계정이 자주 다룰 기업의 브랜드색.

### 방법
1. **역할 토큰 12개**(`naver_cardnews/palette.py`): 배경·보조 배경·제목·본문·출처 / 퍼스널 컬러·그 위 글씨·강조선 / 딥(숫자·비교 카드)·그 위 글씨·팝(큰 숫자) / 형광펜.
2. **60·30·10**: 배경 60 · 잉크 30 · 퍼스널 컬러 10. 퍼스널 컬러는 마무리 배경·강조선·인용부호·vs 배지에만, 보색 살구는 형광펜에만.
3. **수치 검증**: 제목 7:1, 본문·출처·형광펜 위 글씨 4.5:1, 마무리 글씨 4.5:1, 큰 숫자 4.5:1, 강조선 3:1. 다루는 기업 브랜드색(카카오·네이버·배민·토스)과 **LCh 색상각 20° 이상**.
   색차(ΔE)만 보면 밝기 차이 때문에 '같은 노랑'이 통과돼 버려서, 사람이 브랜드를 연상하는 기준인 색상각으로 본다.
4. 렌더 QA 도 실제 글씨 색(흰 글씨/검은 글씨)을 읽어 대비를 잰다.

## v2.4 돌려 쓰는 눈 편한 팔레트 (2026-10-21)

배경·주색을 하나로 고정하지 않고 **6개 팔레트를 순서대로 돌려 쓴다** (`naver_cardnews/palette.py` 의 `ROTATION`).
`make_card` 가 지금까지 만든 카드 수(제작완료+게시완료) % 6 으로 고르고, 쓴 팔레트는 `meta.json` 의 `palette` 에 남겨
`rerender` 가 같은 색으로 다시 그린다. `CARDNEWS_PALETTE=<이름>` 이면 그 팔레트로 고정.

| 이름 | 표시명 | 모드 | 배경 | 퍼스널 컬러 | 형광펜 | 제목 대비 |
|---|---|---|---|---|---|---|
| ocean | 오션 | light | `#F6F5F1` | `#13698F` | `#F8D3C6` | 13.5 |
| clay | 클레이 | light | `#F7F3EE` | `#A0563B` | `#D3E3EE` | 13.7 |
| sage | 세이지 | light | `#F3F5F0` | `#4C6D60` | `#E2DAF0` | 12.6 |
| plum | 플럼 | light | `#F7F3F4` | `#8A4E6A` | `#D6EADD` | 14.0 |
| mono | 뉴스프린트 | light | `#F4F2EE` | `#343A44` | `#E2D6C6` | 14.1 |
| slate | 슬레이트(다크) | dark | `#1D232B` | `#7CAFD3` | `#3A5165` | 12.2 |

**눈 편함 기준 (`COMFORT`, 모든 ROTATION 팔레트가 테스트로 통과해야 함)**
- 제목 대비 ≤ 16:1 — 순흑/순백(21:1)은 눈부심·번짐(헐레이션)이 있어 상한을 둔다. 하한 7:1(AAA)은 기존 CHECKS.
- 배경 채도 LCh C ≤ 8, 밝기 L 91~97.5(밝은 모드) / 10~22(다크) — 넓은 면적은 거의 무채색 종이 톤.
- 마무리 전면 배경 채도 ≤ 50 — 한 장 전체가 원색이면 피로하다.
- 형광펜 채도 ≤ 30, 배경과 색차 ΔE ≥ 8, **노랑 계열(색상각 80~105°) 금지** (사용자 요청).
- 기존 대비 기준(본문 4.5, 출처 4.5, 마무리 글씨 4.5 등)과 국내 앱 브랜드색과의 색상각 ≥ 20° 유지.

다크(slate)도 돌아가도록 `card.css` 의 밝은 배경 가정 색(사진 하단 그라데이션·액자 테두리·마무리 밑줄)을
`color-mix(... var(--bg|--ink|--on-brand) ...)` 로 바꿨다. 비교 시트: `cardnews/output/rotation_compare.jpg`.

## v2.5 무작위 구성: 색 → 레이아웃 → 포맷 → 사진 → 작성 (2026-10-23)

카드 세트마다 아래 순서로 고른다 (`naver_cardnews/compose.py`, `cardnews/make_card.py`).

1. **색**: 눈 편한 팔레트 6종(v2.4) 중 하나
2. **레이아웃**: `templates/layout_*.css` 6종. 색은 역할 토큰(`--bg`, `--brand` …)만 쓰므로 어떤 팔레트와도 조합된다

| 이름 | 표시명 | 사진 비중 | 생김새 |
|---|---|---|---|
| frame | 액자 | 보통 | 둥근 액자 사진 + 큰 번호 워터마크 (기존 기본) |
| fullbleed | 풀블리드 | 큼 | 사진 전면 + 하단 딥 컬러 그라데이션 위 밝은 글씨 (`--overlay:1` → 겹침 검사 대신 대비 검사) |
| split | 매거진 분할 | 큼 | 위 절반 사진(모서리 없음) + 강조선 + 번호 배지 |
| card | 카드 스택 | 보통 | 옅은 퍼스널 컬러 바탕 위 종이 카드 |
| band | 사이드 밴드 | 큼 | 왼쪽 컬러 띠 + 오른쪽 세로 사진 + 큰 번호 |
| type | 타이포 우선 | 작음 | 원형 작은 사진, 글씨가 주도 |

3. **포맷**: 기사 본문 조건을 통과한 포맷만 후보(수치 4개 이상 → numbers, 찬반·우려 어휘 → debate, 현장 어휘 → scene,
   요금·시행 어휘 → qa, 반전 어휘 → reveal, 용어 후보 3개 이상 → glossary, explainer 는 항상)
4. **사진**: 비전 점수(내용) + 팔레트 톤 가산점(최대 +0.5). 무채색 사진은 어떤 색과도, 유채색은 퍼스널 컬러와 유사색·보색일 때 높고
   95° 부근의 어중간한 색상각은 낮다. 풀블리드는 어두운 사진을 더 친다. 합격선(3.0)은 비전 점수만 본다
5. **작성**: 고른 포맷과 기존 원고 포맷이 같으면 재사용, 다르면 그 포맷으로 다시 쓴다

**규칙 있는 무작위**: 직전 게시물과 같은 색·레이아웃·포맷 금지, 최근 6개 안의 (색, 레이아웃) 조합 금지,
사진 비중이 큰 레이아웃은 사진 장 2장 이상 포맷에만, 엑셀에서 고친 원고는 포맷 고정, 기존 AI 원고 포맷이 조건을 통과하고
직전과 다르면 재사용(원고 재작성 비용 절약). 기록: DB `compositions` 테이블, `meta.json` 의 `composition`.
고정: `make_card.py URL --palette sage --layout card --format qa --seed 3` 또는 `CARDNEWS_PALETTE` / `CARDNEWS_LAYOUT`.
비교 시트: `cardnews/output/layout_compare_{ocean_scene,clay_debate,slate_scene}.jpg`.
