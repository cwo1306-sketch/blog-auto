# 카드뉴스 구성 템플릿 (네이버 언론사 카드뉴스 분석 기반, 2026-10-21 v2)

v1(일반 캐러셀 가이드 기반)은 구조가 일반적이라는 지적을 받아, **네이버 뉴스에 실제 올라오는 언론사 카드뉴스**를 받아 읽고 다시 만들었다.
디자인은 `docs/DESIGN_2026.md` v2.1(연한 톤)을 공유한다. 코드: `naver_cardnews/formats.py`, 샘플: `cardnews/samples.py`.

## 1. 무엇을 봤나

네이버 검색 API(`sort=sim`)로 제목에 "[카드뉴스]"가 붙은 n.news.naver.com 기사 28건을 찾았고, 그중 9건의 본문(카드 문구가 그대로 실린다)과
이미지 수를 가져와 읽었다. "네이버 카드뉴스" 전용 섹션 URL은 현재 없고(`/section/cardnews` 404), 언론사가 일반 기사로 송고한 카드뉴스가
IT/과학(105)·생활(103)·경제(101) 섹션에 섞여 있다.

| 매체·시리즈 | 장 수 | 구조 (본문에서 읽은 순서) | 특징 |
|---|---|---|---|
| **ZDNet코리아 [카드뉴스] AMEET** (6건: AI 리터러시 격차, 챗GPT 연령, AI 신약, AI 냉장고 해킹, 대만 반도체, 반도체 100조) | 8 | 질문형 제목 + **수치 부제**("고소득 4.2점 vs 1.8점") → "이런 생각 해보신 적 있으시죠?" **공감 훅** → 핵심 수치 → **"왜 그럴까요?" + 일상 비유**("같은 연필을 줘도 그림 실력은 제각각") → **전문가 찬반 비율**(70% vs 30%, 50%→40%→66%) → 반론·우려 → **상황별 구체 권고**("12세 미만은…, 12~15세는…, 16세 이상은…") → "오늘부터 ~해보세요" **행동 CTA** → 보고서 출처 | 해요체, 본문 830~950자, 매 건 동일 골격 |
| **연합뉴스 [카드뉴스] 우리말 구조대** (AI 시대의 방송 언어) | 10 | 낯선 용어 4개 나열 표지 → 왜 쏟아지나 → **용어 1~4 각 한 줄 정의** → 오용 **사례**(KBS 아르테미스 중계 오역) → **전문가 인용**("세종국어문화원 김슬옹 원장은 …") → 결론 → 시리즈 고정 푸터 | 합니다체, 용어 묶음, 인용 카드 |
| **이데일리 [카드뉴스] K-스마트팜** | 8 | **구체 장면**("뉴욕의 한 대형마트 매장 안") → 작동 방식 → 수치(100억 달러) → 또 다른 수치(32억 4000만 달러) → **또 다른 현장**(사우디 리야드 2000㎡) → 정부 계획(2028년 서산) → 결론 → 제작지원 표기 | **한 장 한 문장(30~50자)**, 사진 중심, 본문 524자 |
| 스브스뉴스 (논문 '카드뉴스의 서사전략과 이미지 내러티브') | — | '의문의 사실 제시' → 단서 → '비밀의 풀림' 추리 서사 | 반전형 |

공통점: **8~10장**(우리 v1은 6장), 표지에 질문 또는 수치, 어려운 원리는 비유로, 전문가 인용·비율이 신뢰 장치, 마지막은 "그래서 이렇게 하세요".

## 2. 템플릿 7종 (표지 1 + 본문 4~6 + 마무리 1)

| format | 이름 · 참고 | 본문 장 수 | 본문 구성 | 쓰는 경우 |
|---|---|---|---|---|
| `debate` | 질문-토론-권고형 · ZDNet AMEET | 6 | 공감 훅 → 핵심 수치(stat) → "왜 그럴까요?" 비유 → 찬반 비율(compare/stat) → 인용·반론(quote) → 상황별 권고(list) | 찬반·권고가 있는 주제 |
| `glossary` | 용어 묶음형 · 연합 우리말 구조대 | 6 | 왜 쏟아지나 → 용어 1~4(term, 한 줄 정의 + 비유) → 전문가 인용(quote) | 낯선 용어 3개 이상 |
| `scene` | 현장 사례형 · 이데일리 | 6 | 장면 → 작동 방식 → 수치(stat) → 또 다른 현장 → 계획 → 의미 (**한 장 한 문장**, photo 본문 25~75자) | 장소·장면이 있는 기사 |
| `reveal` | 반전 추리형 · 스브스뉴스 | 5 | 통념 → 단서 1 → 단서 2(stat) → '알려진 것 vs 실제로는'(compare) → 왜 | 통념과 다른 결론 |
| `qa` | 문답형 · VOX 카드 스택 | 5 | Q 무슨 일 → Q 내 영향 → Q 왜 → Q 언제부터 → '이렇게 하세요'(list) | 정책·서비스 변경 |
| `numbers` | 수치 브리핑형 | 5 | stat × 4 → 결론(photo) | 수치 3개 이상 |
| `explainer` | 설명형(기본) | 4 | 무슨 일 → 왜 중요 → 맥락(stat 가능) → 전망 | 그 외 |

장 유형: photo · stat · list · term · qa · compare · **quote**(신규: 발언 요지 + 인용문 + 발언자). quote 본문은 **원문에 그대로 있어야** 검수를 통과한다.

### 선택 규칙 (`format: auto`)
찬반·권고 → debate · 낯선 용어 3개+ → glossary · 구체 현장 → scene · 통념과 다른 결론 → reveal · 독자 영향 질문 → qa · 수치 3개+ → numbers · 그 외 → explainer.
`draft --format debate`로 강제.

### 말투
ZDNet·이데일리 모두 해요체 또는 짧은 합니다체. writer 기본은 **해요체**, stat·compare·quote 장은 간결체.

## 3. 엑셀 '원고' 시트
본문 열은 2~7장까지 6칸이고 포맷 장 수만큼만 채워진다(빈 장은 무시). quote 는 라벨 열에 발언자, 본문 열에 인용문.
